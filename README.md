# Learning archive

Private archive of my learning projects, organized like the two folders on my Desktop. Existing course material, attribution, and licenses remain with their respective authors.

## Folder layout

```text
learning-archive/
├── Metigator/
│   ├── CRUD-USING-CQRS/
│   ├── EF-Core/
│   ├── Mastering ASP.NET Core/
│   ├── MechanicShopWorkshop/
│   └── ...
└── Programming Advices/
    ├── C#-Projects/
    ├── Course-19-Projects/
    ├── Learning-C++/
    ├── Learn-C#/
    ├── HTML/
    ├── CSS/
    └── ...
```

All original subfolder names are preserved, including spaces, punctuation, and the nested Learning-C++ folder. Empty learning folders use a .gitkeep marker because Git does not store empty directories.

## What is preserved

- `Metigator`: 10 learning groups and 2,764 original named files.
- `Programming Advices`: 15 learning groups and 3,270 original named files.

Source code, project/solution files, resources, documentation, learning videos, and existing course RAR archives are included. See ARCHIVE-MANIFEST.json for paths, sizes, and SHA-256 hashes.

## Snapshot verification

Snapshot prepared on 30 October 2026. All 6,419 non-generated filenames in the saved 29 October inventory of these two folders were present locally. The comparison covers the earlier recorded files, rather than claiming a complete original MEGA cloud inventory. Additional ignored files were included where appropriate. The Desktop originals were read and hash-checked; they were not edited.

## Deliberate exclusions and changes

Generated build/deployment output, dependency folders, IDE caches, nested Git metadata/history, temporary build logs, and MEGA transfer remnants are excluded. This repository starts a new archive history; it does not copy each nested repository's previous Git history. Existing course ZIP/RAR assets and authored resources are retained unless identified as generated deployment bundles.

Embedded database passwords, signing/API keys, and token examples were replaced with clearly named placeholders in 34 files in this upload copy. Filenames and folder locations remain unchanged. Configure appropriate local values before running affected projects. ARCHIVE-NOTES.md lists the modified paths and exclusions. Original Desktop values remain on the machine. This was a text-pattern credential check, not an exhaustive security or runtime audit; existing binary archives were preserved without content rewriting.

## Adding future learning work

1. Add new projects beneath Metigator or Programming Advices, preserving the organization you prefer.
2. Keep the repository private and check new files for personal information or credentials.
3. From this repository root, commit and push your changes:

```powershell
git add -- "Metigator" "Programming Advices"
git commit -m "Add new learning work"
git push
```

The initial manifest describes this snapshot; it is not automatically regenerated by Git. GitHub updates only after committing and pushing. Keep a separate complete backup for excluded data and original local configuration.

## Validation scope

No projects, migrations, or tests were executed to prepare this archive. Filename comparison and file-content/hash verification establish preservation, not that every learning application builds or runs.
